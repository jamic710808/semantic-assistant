# 原樣權限視窗與模型修改總開關

日期：2026-10-14。原始碼實作完成；原生互動及真實 Power BI 寫入驗收尚未執行。

## 使用

關閉舊版視窗，執行根目錄 `Start-Semantic-Assistant.cmd`，點頂部「權限管理」。
獨立視窗參照使用者的 ABI 截圖：標題、單一核取方塊、提示、取消與保存，380 × 250 的 WPF 邏輯尺寸。
保留本專案 Semantic 品牌；標題列由 Windows 繪製，未聲稱不同 DPI 的像素完全一致。

- 勾選「允許 Semantic 智能助手修改資料模型」並保存：解除本助手的模型修改限制。
- 取消勾選並保存：安全模式，禁止新的模型修改。
- 取消或關閉 ×：不保存本次草稿，也不改變已保存的政策。
- 初次沒有該欄位時預設關閉。此為本專案明確設定，ABI 的安裝預設值仍未證實。
- 查詢、獨立 HTML 匯出、AI 模型設定與範本設定不由此開關授權；原有流程與同意仍適用。

原本側面板的「權限」分頁已改名「執行設定」，可從左下「來源與工具」開啟。原有查詢、匯出、工具與預算項目保留在相關操作區，不出現在權限管理對話框。

## 真正接入的寫入路徑

| 路徑 | 接線 |
|---|---|
| 主畫面模型修改 | 共用政策 → ModelWriteWindow → ModelWriteCoordinator → 寫入器防護 |
| 主畫面 HTML 度量值 | 同一政策，預覽與寫入同意皆綁定版本 |
| Dashboard 指標寫入 | 同一政策 → DashboardCoordinator → ModelWriteCoordinator |
| Dashboard 靜態／動態 HTML 度量值 | 子視窗取得同一政策，不能建立獨立允許狀態 |
| 本機 Power BI / 雲端 XMLA / 合成寫入 | 同一個 PolicyControlledModelWriter 包裝各來源寫入器 |
| 未知副作用的 MCP 程序／AI 工具 | 安全模式拒絕程序啟動與工具執行；政策變更使舊工具政策失效 |

總開關是桌面助手的應用政策，不能限制其他程式、其他主機或獨立 CLI 宿主直接使用 Power BI API。應用層協調器提供政策參數，桌面宿主與其子視窗均明確接入；其他宿主需自行提供並持有政策。

## 政策版本與執行時檢查

ModelModificationPolicy 包含 PolicyId、Version、Allowed，真正切換時遞增版本。關閉再開啟不恢復舊版本。

1. 準備模型修改預覽時記錄政策版本。
2. 建立寫入同意時確認預覽所屬版本仍有效且允許。
3. 執行前、寫入器授權回呼、回讀與發布結果前再次檢查。
4. 關閉政策時，舊預覽及同意不能再執行。UI 通知也會清除修改勾選與預覽，必要時取消正在執行的寫入。

真正檢查不依賴畫面按鈕或 UI 通知成功。原有來源版本、物件所有權、一次性同意、結果期限與稽核仍保留。
模型修改總開關開啟後，現有逐次預覽／同意流程仍適用；這次未加入 ABI 的所有 AI 直接修改工具。

## 關閉時的補償與外部工具

外部 SaveChanges 已開始後不能保證立即停止。若政策失效導致本次寫入失敗，仍允許補償還原，但限於防護寫入器確實啟動過的同一 OperationId、計畫雜湊與可驗證自有物件；不能借還原開始另一筆寫入。
回復失敗仍報告部分失敗；不宣稱跨程序原子交易。

MCP 工具由程序提供的 readOnly 標記無法證明沒有副作用，因此安全模式採拒絕未知程序啟動／工具執行。關閉政策時清除本助手的已匯入工具與取消／關閉相關自有程序。已發出的外部操作不能保證撤銷，沒有自動回復任意外部副作用。
這是重建版明確採用的規則；ABI 的所有 MCP 情境尚未核對，不能聲稱此部分已達行為完全一致。

## 保存與相容性

保存位置：`%LOCALAPPDATA%/SemanticAssistant/preferences/settings.json`，增加可選布林欄位 AllowModelModification，沿用設定版本 2。
先保存成功才更新執行時政策；AI 模型清單、目前模型、範本與預算保留。開啟或取消視窗不寫檔。
首次將設定保存至原本沒有此欄位的檔案時，另存 `settings-before-model-permissions-<GUID>.json`。
舊版程式不一定認識新增欄位，請使用新版根目錄啟動入口。無效或未知版本的設定檔不覆寫。
