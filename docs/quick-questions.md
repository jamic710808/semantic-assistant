# 引導式提問：配置與首頁三按鈕串接

日期：2026-10-14。已實作配置、保存及首頁按鈕的同一份設定接線；原生互動與重啟驗收尚未執行。

## 使用

關閉舊版，執行根目錄 `Start-Semantic-Assistant.cmd`，點「引導式提問」，開啟「提問配置」。

1. 選「本地」或「雲端」。
2. 編輯問題 1、2、3，分別對應首頁三個快捷按鈕。
3. 切換類型會暫存目前三個欄位；返回仍可繼續編輯。
4. 按保存，一次保存兩組設定。首頁當前來源的按鈕立即更新。
5. 取消或關閉 × 捨棄本次草稿，不改首頁與已保存設定。

本地 Power BI、合成示範與離線 TMDL 使用本地組；雲端語意模型使用雲端組。切換來源由 ShowWelcome 重新取用對應組；編輯雲端組不會使本地首頁顯示雲端問題。

點擊按鈕會把對應的完整原文填入問答框，不自動送出、不附加分析目標、不使用另一套隱藏提示詞。長文字的按鈕標籤會省略顯示，懸停可看全文；實際填入仍是完整問題。
每題最多1000字、單行，保存時去除前後空白；空白使用對應組的預設問題，配置再次開啟與首頁都顯示相同的有效文字。

## 初始內容

本地組按使用者提供的 ABI 參考文字還原：

1. 介紹這個PowerBI資料模型的基本結構
2. 分析所有的視覺化頁面，並給出優化建議
3. 請幫我創建度量值：

雲端組也有三個獨立欄位。初始種子為本專案自有文字：介紹雲端語意模型、全面探索性分析、創建度量值。因未提供 ABI 的雲端配置畫面，不能聲稱其初始文字完全相同；使用者可以直接編輯。

「分析視覺化頁面」的文字恢復不等於新增報表頁面／視覺物件存取能力。現有引擎仍以語意模型結構與受限查詢為主，相關報表分析功能需後續補齊；這次不再將使用者選定的問題偷偷換成模型優化問題。

## 同一份設定的程式鏈

```text
提問配置欄位
  → QuickQuestionSettings.Local / Cloud（各三題）
  → 保存 AssistantSettings.QuickQuestions
  → RefreshQuickQuestions 依目前來源取用
  → 三個按鈕的文字、完整提示與可及性名稱
  → 點擊時按問題索引，從同一份設定取完整文字
  → FillPrompt → 問答框
```

保存不清除既有問答、查詢結果、目前 AI 模型、範本或模型修改總開關；不建立資料外送、數值查詢或模型修改授權。

## 保存相容性

`%LOCALAPPDATA%/SemanticAssistant/preferences/settings.json` 增加可選 QuickQuestions 欄位，保留設定版本2。沒有此欄位的舊設定載入預設問題，使用者保存前不重寫原檔。
首次保存至原本缺少此欄位的檔案，備份為 `settings-before-quick-questions-<GUID>.json`；AI 模型、範本、預算與權限設定保持原值。
先保存成功才更新主視窗。無效、未知版本或無法驗證的設定檔不覆寫；較舊程式不一定認識新欄位，請使用新版啟動入口。
