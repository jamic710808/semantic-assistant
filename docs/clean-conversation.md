# 主對話只顯示提問與回答

日期：2026-10-14。

## 修正原因

原本桌面回合處理把 ConversationEvent 的 Started、ToolStarted、ToolCompleted、Completed、Error 等事件直接拼接到 Transcript；AI 呼叫工具前的中間文字也會立即出現在主對話。這將診斷過程混入面向使用者的對話，與使用者要求的 ABI 互動方式不符。

## 本次行為

- 主對話只加入使用者提問，以及成功完成並通過來源／當次授權核對的最終 AI 回答。
- 不顯示工具名稱、工具呼叫、讀取摘要、DAX 執行預告、事件標籤、舊脈絡省略紀錄或本機模型修改的技術收據。
- AI 串流中的中間文字不加入正文；回合結束後使用 ConversationOutcome.Answer 顯示完成回答，不以工具摘要代替 AI 回答。
- 等待期間顯示「正在思考…」。失敗／取消訊息留在狀態區，不把錯誤事件拼進對話。
- 技術事件留在「查詢結果 → 結果與匯出 → 執行紀錄」；預設收合，不自動開啟。只保留本機記憶體中的當次紀錄，最多32,000字元，不保存完整 provider 中間文字或原始結果 payload。
- 模型修改結果在狀態區與結果面板顯示；後端回讀收據仍按既有規則作為下回合有效脈絡，主對話不插入技術收據。
- 「複製全部對話」只複製提問與回答。「複製最新回答」沿用最新成功完成的 Markdown 回答。

模型工具、唯讀概覽、權限檢查、資料外送授權及寫入預覽仍使用既有鏈路。最終回答若有分析所需的欄位、公式與資料依據，仍完整顯示；不以字串過濾刪除 AI 回答内容。
