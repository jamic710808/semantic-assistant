# 桌面主畫面重建

## 參考與範圍

以使用者 2026-10-13 提供的 ABI Assistant 主畫面截圖為版面參考，使用本專案 WPF 原始碼重建。
本次交付包含主畫面、工具入口、權限／來源／結果側面板，以及引導提問視窗。
品牌顯示為「Semantic 智能助手」。未從 ABI 安裝目錄複製程式碼或圖像資源。

參考圖為 998 × 646；預設視窗使用相同邏輯尺寸，最小 940 × 600，可調整大小。
視窗縮放、字體、原生視窗操作及各個既有對話框，仍需在實際桌面檢視。
主畫面還原不代表整套 ABI 功能或所有 UI 狀態已達成像素一致。

## 啟動入口

專案根目錄：`啟動 Semantic 智能助手.cmd` 或 `Start-Semantic-Assistant.cmd`。
目前啟動入口固定指向 `app/SemanticAssistant.Desktop.dll`（1.0.1 開發版）。2026-10-15 整理後已移除過時的 `啟動 AI 修正版.cmd` 及舊 artifacts 程式包。
最新版包含提問配置與首頁三按鈕串接、獨立權限視窗與總開關、三分頁範本、多模型 AI 配置與先前修正。提問配置見 [quick-questions.md](quick-questions.md)，權限見 [model-permissions.md](model-permissions.md)，AI 配置見 [ai-model-profiles.md](ai-model-profiles.md)，範本見 [report-templates.md](report-templates.md)。

## 功能映射

| 入口 | 實際操作 |
| --- | --- |
| 連接本地報告 | 原有 Desktop instance 與模型選取流程 |
| 雲端語意模型 | 原有 Power BI 雲端登入與模型選取流程 |
| AI 配置 | 原有供應商設定與 Windows 憑證保管 |
| 範本 | 三分頁版型、配色、合成預覽與保存，接入對應報告輸出 |
| 權限管理 | 原圖布局的獨立視窗；保存模型修改總開關，取消不保存 |
| 引導式提問 | 提問配置視窗：本地／雲端各三個問題，保存後同步首頁按鈕 |
| 語言 | 顯示目前提供的繁體中文介面 |
| 左側模型樹 | 模型根節點、表、度量值與關係；選取物件檢視原始結構 |
| 快捷提問 | 填入提問，等待使用者送出 |
| 底部模式 | 報告、HTML、Dashboard；「分析」回到結構分析，完整五種模式在來源與工具面板 |
| 迴紋針 | 開啟 TMDL 資料夾，未實作任意附件上傳 |
| + | 新對話，清除當次結果與授權 |
| 歷史圖示 | 原有本機歷史與保存政策視窗 |
| 左下「查詢結果」 | 結果、報告視覺、HTML 匯出與 Dashboard 提案側面板 |
| 左下「來源與工具」 | 執行設定、模型來源與工具側面板 |

Enter 送出，Shift + Enter 換行；空白訊息不能送出。
快捷提問會填入保存的問題原文；送出仍需設定與授權。「引導式提問」管理這三個按鈕的內容，不會送出 AI 請求。範本配置可獨立使用，保存或預覽不連線 AI 或 Power BI。
歡迎區與對話捲動區交替顯示，避免空白捲動區擋住提示詞按鈕。
功能仍走原有模式控制與授權流程。
快捷問題的本地初始文字已按參考圖恢復，並可由提問配置修改；目前引擎仍主要處理語意模型，配置文字不代表已加入報表視覺頁面讀取能力。

## 原始碼

- `MainWindow.xaml`：主畫面、視覺樣式與側面板。
- `MainWindow.Shell.cs`：新介面入口、模式按鈕、引導式提問、視窗控制。
- `MainWindow.xaml.cs`：接回既有流程，模型樹與狀態呈現。
- `App.xaml.cs`：獨立合成模型預覽輸出，未顯示原生視窗。

## 預覽與驗收邊界

可用 `--render-ui-preview <PNG 路徑>` 產生 998 × 646 主畫面預覽。
此流程只使用內建合成模型，不還原使用者設定、不讀取憑證、不連線到 Power BI 或 AI。

本次執行編譯與 WPF 靜態呈現，未執行測試套件、真實 AI／Power BI 請求或原生視窗互動驗收。
下一步可延伸對話泡泡與結果卡片，以及供應商、權限及其他既有視窗的視覺一致性。
