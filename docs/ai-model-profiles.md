# AI 配置：多模型保存與啟用

## 使用方式

1. 在主畫面按「AI 配置」。
2. 「新增模型」：填寫顯示名稱、完整 Chat Completions 端點與供應商模型名稱；需要驗證時填入 API key。
3. 「保存設定」：保存新增或修改的模型；新增模型不會自動取代目前啟用的模型。
4. 「設為目前使用」：啟用已保存的模型，主畫面左下同步顯示名稱；重新啟動會沿用。
5. 「刪除模型」：確認後移除設定及其 key；刪除目前使用的模型會切回本機模擬 AI。

左側選取不同模型可檢視與編輯；「目前使用」標記與選取狀態分開。
未保存的修改會標示，切換選取、新增或關閉前會提醒是否捨棄。
修改目前使用模型的端點、模型或 key 時，保存後會更新目前設定並撤銷舊回合授權。
返回本機模擬 AI 不會刪除模型清單或憑證。

## API key

- API key 僅保存於 Windows 認證管理員，不寫入模型設定 JSON、不回填、不顯示。
- 選取模型時只查詢憑證是否存在，顯示「已有保存的 key」或未保存狀態。
- 空白沿用此模型的既有 key。修改端點或模型時，保存流程會將原 key 移轉到新的憑證目標。
- 填入新 key 會替換該模型的 key；勾選「清除」會移除，不可同時填入新 key。
- 每組模型使用獨立 ID；新增同一端點／模型仍可有各自的 key。
- 若設定保存失敗，嘗試回復該次變更前的憑證；回復失敗會明確顯示需要重新設定。
- 刪除設定後若憑證清理失敗，畫面會告知；不把清理失敗寫成已完成。

## 本機保存與既有設定

預設位置：`%LOCALAPPDATA%/SemanticAssistant/preferences/settings.json`。
沿用設定版本 2，增加可選 `AiProfiles` 欄位，保存顯示名稱與 ProviderIdentity；`AiProvider` 表示目前使用。
舊版單一供應商設定在載入時加入記憶體模型清單，保留原憑證 ID；使用者保存前不重寫原檔。
第一次將原本沒有 `AiProfiles` 的設定保存為模型清單時，會額外保留一份
`settings-before-ai-profiles-<隨機識別碼>.json`。
設定寫入採暫存檔加替換；未知、無效或無法驗證的設定仍不覆寫。
最多 24 組模型，設定檔上限 128 KB。

## 與參考畫面的差異

支援顯示名稱、API key、端點、模型名稱、增刪改保存與目前模型切換。
目前引擎只提供文字與工具對話，未加入圖片理解／圖片上傳能力設定。
保存或切換不會連線；按送出即使用目前供應商分析，當次授權由程式建立，不再跳出逐回合外送視窗。詳 [直接送出與格式化對話](readable-chat.md)。

## 本輪完成與驗收界線

原始碼、桌面建置與合成配置畫面呈現。未執行測試套件、原生視窗互動驗收、使用者憑證增刪改或真實 API 呼叫。
`--render-ai-profiles <PNG 路徑>` 以合成模型資料呈現畫面，不保存設定；只查詢合成 ID 的憑證存在狀態。
下次可檢查：新增後重啟保留、切換目前模型、修改既有模型、刪除與 key 清理，以及真實供應商回合。
