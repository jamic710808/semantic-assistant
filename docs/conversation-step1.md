# 第一階段：自然語言模式、連續會話與產物

日期：2026-10-14。對應 [功能對齊審查](abi-parity-review-20261014.md) 的第一階段。

後續版本已加入 [第二階段模型工具與部署更新](model-tools-step2.md)。本文件保留第一階段交付時的功能界線。

## 實作範圍

既有 WPF／Application／AI adapter 分層不變，補齊相互缺少的資料與入口。採用共同會話與文件合約，避免各模式各自維護互不相通的文字與產物。沒有複製 ABI 私有程式碼或提示詞，也沒有新增套件。

| 模式 | 送出需求後 | 後續操作 |
|---|---|---|
| 分析 | 模型分析，必要時使用已授權讀取／查詢工具 | 可追問、切換報告模式或匯出 |
| 報告 | 按報告專用指令產生完整正文與章節 | 可要求調整段落，輸出更新後完整文件 |
| HTML | 產生完整報告正文，由本機套用版型輸出 HTML | 勾選本機 HTML 匯出後可直接產生並開啟檔案；未勾選時使用回答下方的匯出按鈕 |
| Dashboard | 依需求呼叫 propose_dashboard；接受有效計畫後開啟預覽 | 同一來源版本下可追問修改計畫；寫入仍須另行預覽與同意 |

進階「HTML 度量值」維持受控的寫入入口。ModeRoute 仍描述各模式的產物操作，新增 EnsureConversation 判斷四種主要模式的自然語言入口；路由不授予寫入能力。

## 操作

1. 關閉舊版助手，再使用根目錄 `Start-Semantic-Assistant.cmd`，或原有中文啟動器。
2. 選擇來源與 AI 模型，選報告／HTML／Dashboard 模式，輸入需求並送出。
3. 真實 AI 的當次外送視窗會說明可用前文；需要沿用前次查詢數值時，需允許該類資料外送。這不代表同意新的數值查詢。
4. 追問例如「保留剛才的分析，把建議改為三項」；切換模式保留同來源／供應商下的內容，但撤銷操作同意。
5. 回答下方提供「匯出／開啟 HTML 報告」與有效 Dashboard 的「檢視 Dashboard 計畫」。未同意匯出時會展開執行設定供勾選；再按匯出。

快捷提問只填入文字、聚焦輸入框，保留目前模式。

## 會話與文件合約

- `ConversationRequest`／`ProviderRequest` 增加 ResponseIntent 與 History；舊呼叫端沒有指定 intent 時仍按 Analyze／Report 推定。
- `ConversationCoordinator` 保存最終回答至 ConversationOutcome.Answer；工具前的過渡文字仍顯示，但不取代文件正文。
- `ConversationSession` 保存最多 12 個成功完成回合，總計最多 64000 字元。只在記憶體中保存，不修改既有磁碟歷史政策。
- 舊回合以 user／assistant 文字重送，不重放舊 tool_call_id 或已執行工具，也不恢復 PermissionSession。
- Dashboard 完整 plan 與雜湊作為前文的一部分，支持修改尚未部署的計畫；計畫每次仍要重新通過本機結構驗證。
- `ReportDocument` 保存文件 ID、來源、供應商、需求、意圖、最終 Markdown、當次查詢及衍生資料的效期依賴。
- 報告／HTML 匯出保留正文，而非只匯出最後查詢。存在當次查詢時沿用既有表／KPI／柱／線輸出與樣式選擇。
- 沒有當次查詢也可以產生與匯出結構說明報告，包括離線 TMDL 分析。

## 來源、授權與效期

- 切換模型來源／版本、供應商或有效 key，以及新對話，都清除舊會話與產物。切換模式只撤銷當次同意，保留內容。
- 前文標記所需外送類別；不符合本次同意的整個回合會省略。UI 告知省略數量。
- 由查詢或 MCP 結果衍生的回答、後續衍生報告亦保留效期依賴。過期資料不能藉文字摘要重新外送，或藉追問延長為新鮮資料。
- AI adapter 在建 payload、HTTP 送出前及串流回合檢查前文授權／效期；coordinator 在模型讀取後、工具迴圈與最終接受時亦檢查。
- 最多128份效期依賴；選前文時留出8份給本回合工具，超過預算的舊回合也會省略。表結構本身不累積成永久工具 payload。
- HTML 正文經編碼輸出，AI 文字不成為腳本、HTML 或檔案路徑。固定主機資料夾、新檔名、既有匯出能力與檢查仍有效。
- 取消／超時／授權失效／供應商錯誤的回合不加入成功會話。原本已成功的文件可保留，但不當成失敗回合的新產物。

## 與後續階段的界線

本階段沒有加入一般模型新增／更新／刪除工具，也沒有 ABI 的 Dashboard registry、已部署看板列舉／更新工具。模型寫入造成版本切換後會清除舊會話；已部署看板的追問需要第二階段接回讀與管理合約。

仍未完成嵌入式 Markdown／互動圖表、訊息重試／複製、完整 Markdown 語法、多模態附件、RLS／報表頁面脈絡，以及跨重啟的完整聊天恢復。HTML 文件目前支援安全的標題、章節、正文與程式碼區塊；其他 Markdown 語法保留為可讀文字。

本機模擬 AI 只走固定合成流程，不能用它的文字品質證明真實模型的追問能力。範本為自有輸出器，仍非 ABI 全目錄與排版的等價證明。
